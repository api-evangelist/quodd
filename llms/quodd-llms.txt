# QUODD

> QUODD is a cloud-native market data provider delivering real-time, delayed, historical, end-of-day, and point-in-time pricing, plus reference data, a security master, fundamentals, estimates, corporate actions, ESG, and news across global equities, ETFs, options, fixed income, FX, funds, and indices. The QUODD Developer Platform documents a token-authenticated REST API and gRPC services for pricing snapshots, ticker fundamentals, and option lookup. Developer documentation is public; production access is gated behind trial or firm credentials and enterprise agreements.

Authentication: exchange a username and password for an access token (POST Token for Trial User / Token for Firm User); the token is appended to REST requests as the `_token` query parameter and expires after 24 hours. gRPC requests carry the JWT as a `Authorization: Bearer` metadata entry; the Snap gRPC service also requires an `AssetType` metadata header (`Equities` or `Options`).

## APIs

- [REST API reference](https://developer.quodd.com/docs/rest-api): Snap, Batch Snaps, Options Snap, Batch Options Snaps, plus token generation
- [Snap gRPC API](https://developer.quodd.com/docs/snap-grpc-api): streaming and request/response snapshots (SnapService at api.quodd.com:443)
- [Ticker Info gRPC API](https://developer.quodd.com/docs/ticker-info-grpc-api): basic fundamentals per ticker (TickerInfoService)
- [Option Lookup gRPC API](https://developer.quodd.com/docs/option-lookup-grpc-api): options tickers and expirations (OptionLookupService)
- [Snapshots overview](https://developer.quodd.com/snapshots): feeds - Realtime, Delayed, Nasdaq Basic; MX Feed coming soon

## Notes

- QUODD does not publish its literal REST base URL or exact endpoint paths openly; the OpenAPI paths above are honestly modeled from the documented operation surface.
- No first-party SDKs on public package registries; gRPC client examples (C#, Go, Node, Ruby) ship as zip downloads with the proto files.
- No public status page, webhook surface, or AsyncAPI is documented; Cloud Streaming's transport is not publicly specified (third-party WebSocket access exists via Intrinio).
